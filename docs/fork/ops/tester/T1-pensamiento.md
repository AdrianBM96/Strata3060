# T1 — pensamiento (problema lógico corto)

- **Ejerce**: razonamiento breve que termina en respuesta comprobable (contenido tipo "pensamiento" de §17).
- **Prompt exacto**: `Si 3x+7=22, ¿cuánto vale x? Responde solo con el número, sin nada más.`
- **Sandbox**: `/tmp/tester-sbx` (no usa ficheros).
- **Límite**: 120 s.
- **Éxito automático**: la salida contiene `5` como respuesta (línea con solo `5` o `x = 5`/`x=5`).
- **Duración esperada**: <1 min.
